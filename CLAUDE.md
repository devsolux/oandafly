## Claude Code

- Stay on `main`: no feature branches, worktrees or pull requests for this repository
  unless the owner asks. Commit to `main` and push with `git push origin main` only when
  asked.
- Use the project interpreter `.venv/bin/python` (Python 3.13) for tests, Ruff and the
  integrity scripts.
- Regenerate and verify `PACKAGE_MANIFEST.json` before every commit (see `AGENTS.md`).
